# Бот для канала о технологиях Китая

Собирает новости из ~10 источников, отсеивает мусор, переписывает через DeepSeek
в готовый пост на русском и присылает вам в личку с кнопками. Вы жмёте «В очередь» —
пост уходит в канал в ближайший разрешённый слот.

Крутится на GitHub Actions, свой сервер не нужен, мак может быть выключен.

```
источники → предфильтр → дедуп → DeepSeek → вам в личку с кнопками
                                                      ↓
                                              очередь → канал по слотам
```

## Быстрая настройка

Если у вас есть токен бота, ключ DeepSeek и аккаунт GitHub — всё делает один скрипт:

```bash
cd ~/Documents/china-tech-bot && ./setup.sh
```

Он поставит `gh` (если нет), создаст приватный репозиторий, сам определит ваш
chat_id, проверит ключ DeepSeek и канал, запишет секреты и запустит первый сбор.
Токены вводятся в вашем терминале и в репозиторий не попадают.

Ниже — то же самое руками, если скрипт по какой-то причине не подошёл.

## Что нужно один раз настроить

### 1. Бот и канал

1. [@BotFather](https://t.me/BotFather) → `/newbot` → скопируйте токен.
2. Создайте канал, добавьте бота администратором с правом публиковать сообщения.
3. Напишите своему боту в личку `/start` — он ответит вашим `chat_id`.
   (Чтобы получить ответ, бот должен хоть раз запуститься: шаг 4 ниже,
   либо локально `python -m bot.moderate`.)

### 2. Ключ DeepSeek

[platform.deepseek.com](https://platform.deepseek.com) → API keys. Пополнение —
от пары долларов, этого хватает на месяцы: один пост стоит доли цента.

### 3. Репозиторий

Создайте **приватный** репозиторий на GitHub и залейте туда этот проект:

```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin git@github.com:ВАШ_ЛОГИН/china-tech-bot.git
git push -u origin main
```

### 4. Секреты

Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_CHANNEL_ID` | `@имя_канала` или `-100…` |
| `MODERATOR_CHAT_ID` | ваш chat_id из шага 1 |
| `DEEPSEEK_API_KEY` | ключ DeepSeek |

Там же Settings → Actions → General → Workflow permissions → **Read and write
permissions**. Без этого бот не сможет сохранять состояние.

### 5. Запуск

Actions → `collect` → Run workflow. Через минуту первые посты придут вам в личку.

## Как это работает каждый день

`collect` просыпается пять раз в день (08:10, 11:10, 14:10, 17:10, 20:10 по Минску),
собирает новости за последние 20 часов, отбрасывает уже виденное и не относящееся
к теме, и прогоняет через DeepSeek не больше пяти штук за раз. Модель может сама
отказаться («это пресс-релиз без фактуры») — такие до вас не доходят.

`moderate` просыпается каждые 10 минут и применяет то, что вы нажали. Отсюда
задержка: между нажатием кнопки и публикацией проходит до 10 минут. Это плата за
работу без своего сервера.

Кнопки под каждой карточкой:

- **✅ В очередь** — пост уйдёт в канал в ближайший слот (не чаще чем раз в 90 минут, с 9 до 22, максимум 6 в день).
- **⚡ Сразу** — публикация немедленно, минуя очередь.
- **♻️ Переписать** — другой заголовок и другой угол подачи на тех же фактах. До трёх раз.
- **🗑 Удалить** — новость исчезает, повторно не предложится.

Команды в личке боту: `/queue` — что в очередях, `/next` — опубликовать следующий
одобренный прямо сейчас, `/id` — показать chat_id.

## Картинки

Каждый пост уходит с картинкой. Бот берёт её так:

1. Фото из самого фида — `enclosure`, `media:content`, `media:thumbnail` или первый
   `<img>` в теле заметки.
2. Если в фиде пусто — открывает страницу статьи и читает `og:image` / `twitter:image`.
3. Если и там ничего — рисует свою карточку: заголовок на фоне цветов канала
   с иероглифом 明 водяным знаком.

Картинка скачивается и загружается в Telegram файлом, а не ссылкой: так надёжнее,
многие сайты не отдают изображение по запросу от Telegram. Мелкие картинки
(меньше 400×220), логотипы, спрайты и трекинг-пиксели отсеиваются, webp
конвертируется в jpeg.

Режим настраивается в `config/channel.yml`, блок `media`:

| `mode` | что делает |
|---|---|
| `source_or_card` | фото источника, иначе своя карточка (по умолчанию) |
| `source_only` | только фото источника, иначе пост уходит текстом |
| `card_only` | всегда своя карточка, чужие фото не трогаем |
| `off` | без картинок |

Там же меняются цвета карточки — `card_bg` и `card_fg`.

Важное ограничение Telegram: подпись к фото не может быть длиннее 1024 символов.
Поэтому длина постов в промпте выставлена в 500-800 символов. Если пост всё же
не влезет, он уйдёт текстом со ссылкой-превью — бот решит это сам и напишет об
этом в карточке модерации.

Про видео: из новостных лент его взять неоткуда — RSS отдаёт текст и картинку.
Ролики пришлось бы искать на YouTube по теме новости и перезаливать, а это
и чужой контент, и совсем другая история по качеству попадания. Если захотите
видео — это отдельная ручная рубрика, а не то, что стоит автоматизировать.

## Что менять под себя

`config/channel.yml` — голос канала. Блок `voice` целиком уходит в промпт, это
главный рычаг: перепишете его — изменится вся подача. Там же расписание публикаций
и лимиты.

`config/sources.yml` — источники. `enabled: false` выключает, не удаляя. `weight`
поднимает или опускает приоритет источника. Чтобы добавить публичный
Telegram-канал, впишите его username в блок `telegram` — читается через веб-превью
`t.me/s/…`, API-аккаунт не нужен.

`config/filters.yml` — предфильтр до LLM: сущности, темы, стоп-слова, порог
`min_score`. Он экономит деньги, отсекая мусор до обращения к модели. Если постов
приходит слишком мало — понижайте `min_score`; если много шума — поднимайте.

`prompts/post_ru.md` — сам промпт: структура поста, правила, критерии отказа.

## Локально

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # впишите свои ключи

python scripts/check_sources.py   # живы ли источники
python -m tests.test_pipeline     # оффлайн-тесты, сеть не нужна
DRY_RUN=1 python -m bot.collect   # прогон без отправки в Telegram
```

`DRY_RUN=1` печатает, что было бы отправлено, и не трогает файлы состояния.
DeepSeek при этом вызывается по-настоящему — так вы увидите реальные тексты постов.

## Состояние

Всё лежит в `state/*.json` и коммитится обратно в репозиторий после каждого запуска:
`seen.json` — что уже видели (последние 1500 новостей, для дедупа), `queue.json` —
карточки на модерации, `approved.json` — одобренное в ожидании слота,
`published.json` — история публикаций, `offset.json` — позиция чтения апдейтов Telegram.

Если что-то пошло вразнос — удалите содержимое `state/*.json` (оставив `{"items": []}`)
и закоммитьте. Бот начнёт с чистого листа.

фора, если канал будет бороться за скорость.

## Чего бот не делает

Не подбирает картинки — в посте показывается превью ссылки на источник.
Не пишет лонгриды и не ведёт рубрики. Не отвечает на комментарии.
Не публикует ночью и не выдаёт пачку постов подряд.
